# comparison-table

- Compatibility: variance 1-5, density 4-8, energy 2-5.
- Use: comparable alternatives, evidence sources, methods, or decisions.
- Not for: prose that cannot be normalized into columns.
- Sketch: action title; restrained header rule; three to six rows; one emphasized cell/row.
- Budget: normally three to five columns and no more than six main rows.
- Typography/spacing: table text normally at least 16 pt; use whitespace and light rules before boxes.
- Assets: native PPT table or aligned text/rule system.
- Anti-patterns: every cell filled, heavy grid borders, decorative heatmap colors.
- QA: alignment, units, row/column labels, emphasis meaning, backup split for overflow.
