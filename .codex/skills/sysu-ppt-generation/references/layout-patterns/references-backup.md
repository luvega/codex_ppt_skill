# references-backup

- Compatibility: variance 1-4, density 5-8, energy 1-3.
- Use: references, methods detail, robustness checks, and questions backup.
- Not for: main narrative evidence that should be visible during the talk.
- Sketch: stable title/footer; grouped references or one backup exhibit per slide.
- Budget: references split when readability falls below 14 pt; backup figures remain projection-readable.
- Typography/spacing: reference text may be 12-14 pt; figure labels follow scientific QA rules.
- Assets: citations, supplementary figures, detailed tables, method diagrams.
- Anti-patterns: a single unreadable bibliography wall, hidden provenance, density 9-10.
- QA: citation completeness, readable grouping, clear backup labeling, preserved slide numbering.
