# PPT Layout Pattern Library

Choose a pattern before drawing custom shapes. Each pattern defines a content budget, layout intent, failure modes, and QA focus. `template-mapping.json` should record the selected `layout_pattern_id` for every slide.

| Pattern ID | Primary use |
|---|---|
| `section-divider` | chapter transition |
| `action-title-hero-visual` | one claim plus one dominant visual |
| `full-figure-evidence` | evidence-first results page |
| `figure-plus-interpretation` | figure with concise interpretation |
| `two-column-teaching` | coordinated explanation or concept/example |
| `comparison-table` | comparable options, evidence, or decisions |
| `process-or-causal-flow` | workflow, mechanism, or causal chain |
| `claim-summary` | synthesis and actions |
| `references-backup` | references, methods detail, and appendix |

Every pattern file uses the same sections: compatibility, use/not-for, sketch, content budget, typography/spacing, assets, anti-patterns, and QA.
